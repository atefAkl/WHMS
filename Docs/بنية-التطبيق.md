## 3. المسارات (Routes)

### مسارات الدومين المركزي — `routes/web.php`

تعمل على: `whms.test` و `whms.loc` و `127.0.0.1`

```
GET  /                          → Welcome (صفحة ترحيب)
POST /register-warehouse        → TenantRequestController@store (تسجيل مستأجر جديد)
GET  /register-warehouse/pending → TenantRequestController@pending

[auth]
GET  /saas/tenants              → SaaSController@index (لوحة إدارة المستأجرين)
POST /saas/tenants/{req}/approve → SaaSController@approveRequest
POST /saas/tenants/{req}/reject  → SaaSController@rejectRequest
```

### مسارات المستأجر — `routes/tenant.php`

تعمل على كل الدومينات الفرعية، مع middleware:
`web → InitializeTenancyByDomain → PreventAccessFromCentralDomains`

```
GET  /setup-password            → TenantPasswordSetupController (أول دخول بالتوكن)
POST /setup-password

[auth]
GET  /tenant-setup              → TenantSetupController (إعداد بيانات الشركة)
POST /tenant-setup
GET/POST /api/settings          → TenantSettingsController

[auth → tenant middleware]
GET  /select-season             → SeasonSelectionController

[auth → tenant → season middlewares]
GET  /dashboard
GET  /pallets
CRUD /customers (+ contacts)
GET|POST /contracts
GET  /contracts/{id}
PUT  /contracts/{id}
POST /contracts/{id}/activate|suspend|end|cancel|periods|contacts|invoices|payments
GET  /agents + POST /agents

/settings/
  general (GET/POST + file upload/delete)
  countries (CRUD + seed)
  categories (CRUD)
  storage-items (CRUD)
  terms (CRUD + settings)
  seasons (CRUD + blocks)
```

## 4. الـ Middleware Chain

```
طلب HTTP
    ↓
web (sessions, CSRF, Inertia)
    ↓  [مسارات المستأجر فقط]
InitializeTenancyByDomain   → يعرف المستأجر من الدومين الفرعي ويفتح DB الخاصة
PreventAccessFromCentralDomains
    ↓
auth                        → يجب أن يكون المستخدم مسجلاً دخوله
    ↓
tenant (alias)              → EnsureTenantIsConfigured
                              يتحقق: هل يوجد company_name في contract_settings؟
                              إذا لا → redirect /tenant-setup
    ↓
season (alias)              → EnsureSeasonIsSelected
                              يتحقق: هل هناك active_season_id في الجلسة؟
                              إذا لا → redirect /select-season
    ↓
Controller
```

## 6. دورة حياة المستأجر (Tenant Lifecycle)

```
1. زبون يملأ نموذج التسجيل
   → POST /register-warehouse → TenantRequest (status: pending)

2. الإدارة تعتمد الطلب
   → POST /saas/tenants/{req}/approve → SaaSController@approveRequest
   ├── ① Tenant::create(id = requested_subdomain)
   ├── ② tenant->domains()->create('slug.whms.test')
   ├── ③ artisan tenants:migrate --tenants=[id]   (ينشئ DB المستأجر)
   ├── ④ tenant->run(fn) → User::create + ContractSetting::create
   ├── ⑤ TenantRequest->update(status: approved, activation_link)
   └── ⑥ Mail::to()->send(TenantActivationMail)

3. الزبون يفتح رابط التفعيل
   → GET slug.whms.test/setup-password?token=xxx
   → يضع كلمة مرور → يُسجَّل دخوله تلقائياً

4. أول دخول: EnsureTenantIsConfigured يوجهه لـ /tenant-setup
   → يملأ بيانات الشركة → contract_settings

5. أول دخول: EnsureSeasonIsSelected يوجهه لإنشاء موسم
   → يختار/ينشئ موسم → session('active_season_id')

6. الدخول للوحة التحكم الكاملة
```

## 10. إعداد Apache (Laragon) المحلي

**الملف:** `c:\laragon\bin\apache\httpd-2.4.66-...\conf\extra\httpd-vhosts.conf`

Laragon يحل DNS لـ `*.test` تلقائياً عبر DNS داخلي.  
يحتاج Apache إلى VirtualHost wildcard لاستقبال كل `*.whms.test`.

**التكوين المطلوب (غير مضاف بعد):**

```apache
<VirtualHost *:80>
    ServerName whms.test
    ServerAlias *.whms.test
    DocumentRoot "C:/laragon/www/WHMS/public"
    <Directory "C:/laragon/www/WHMS/public">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```
