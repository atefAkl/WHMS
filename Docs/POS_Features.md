# إجمالي مميزات وخصائص هذه الواجهة الذكية

## Reception View Features

تضم صفحة إنشاء وتعديل سندات الاستلام `CreateEdit.jsx` مجموعة متطورة ومتكاملة من الخصائص المصممة خصيصاً للسرعة وتسهيل تجربة المستخدم.

## المميزات الرئيسية

### إدارة وحفظ المسودات التلقائية
`Active Drafts Switcher`

- بمجرد نقر المستخدم على "جديد"، يتم إنشاء سجل مسودة فوري برقم مسلسل وتاريخ اليوم لتجنب أي تعارضات تشغيلية بين الأجهزة.
- يعرض الشريط العلوي المسودات المعلقة للتبديل السريع بينها مع حفظ تلقائي للمسودة المفتوحة حالياً.

### الإكمال التلقائي الذكي للعملاء
`Customer Search Autocomplete`

- حقل بحث تفاعلي مع كتابة العميل.
- يظهر قائمة منسدلة سريعة تدعم تصفح الخيارات بأسهم لوحة المفاتيح `ArrowUp` و`ArrowDown`.
- يمكن اختيار العنصر بالضغط على `Enter` مع منع الإرسال العشوائي للنموذج.

### الربط التلقائي والاعتمادات
`Contract Dependency Auto-Loading`

- عند تعيين العميل، يتم جلب عقوده النشطة، وفترات الفوترة، ومندوب العميل الافتراضي.
- يتم تعبئة هذه البيانات تلقائياً لتسريع إدخال الرأسيات.

### شريط الإدخال السريع بالكامل من لوحة المفاتيح
`POS Quick Entry Bar`

- شريط سريع لإدخال بنود الاستلام يعتمد كلياً على الكيبورد.
- يتنقل المستخدم بين الحقول بالأسهم الجانبية.
- يختار العبوات بأسهم التوجيه.
- يدرج الصف بالضغط على `Enter`.

### لوحة إشغال وسعة العقد اللحظية
`Live Capacity Tracker`

- تحسب اللوحة الجانبية السعة الكلية والكمية الحالية وسعة التخزين المتبقية.
- تتحدث البيانات لحظياً بحسب الأصناف المضافة حديثاً في الجدول قبل الحفظ الفعلي.
- اللوحة قابلة للطي بالكامل لتوفير المساحة بضغطة زر.

### لوحة معلومات السند الأساسية القابلة للطي
`Collapsible Voucher Info`

- تمكن المستخدم من طي لوحة المدخلات الرئيسية بالكامل بعد تعبئتها.
- يساعد ذلك على التركيز على جدول البنود والاستفادة من المساحة الرأسية كاملة.

### نافذة تسجيل السائقين السريعة
`Driver Quick Setup Modal`

- تسجيل بيانات السائق الناقل ورقم اللوحة.
- إضافة السائق مباشرة إلى الحقل المستهدف دون مغادرة الصفحة أو فقدان تقدم العمل.

### مفاتيح اختصارات العمليات الشاملة
`Layout-Independent Keyboard Shortcuts`

- `Ctrl + Shift + S`: حفظ كمسودة فارغة أو مكتملة والعودة للفهرس.
- `Ctrl + S`: حفظ كمسودة والاستمرار في التعديل بنفس الصفحة.
- `Ctrl + E`: حفظ واعتماد السند نهائياً والانتقال المباشر إلى صفحة الطباعة `Print.jsx`.
- `Ctrl + D`: إظهار نافذة الحذف الفورية للسند.

### نافذة الحذف والاعتماد الآمن
`Secure Confirm Deletion Modal`

- تطلب كلمة مرور الحفظ أو الحذف الآمنة للمستخدم لتنفيذ العمليات الحساسة.
- تساعد على منع أي حذف بالخطأ.

### شريط الأدوات الأيقوني الذكي
`Tooltipped Actions Bar`

- أزرار أيقونية موفرة للمساحة.
- تعرض تلميحات توضيحية عن وظيفة كل زر.
- تُظهر اختصار الكيبورد المقابل عند التحويم عليها.
